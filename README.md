# Sistema de gestion de tareas

Proyecto Java Web estructurado con MVC :

- `controller`: Servlets que reciben peticiones y seleccionan vistas.
- `dao`: Acceso a datos con JDBC directo.
- `model`: Entidades acordes a la base de datos `gestion_tareas`.
- `util`: Conexion MySQL y utilidades.
- `WEB-INF/views`: JSP protegidas del acceso directo.
